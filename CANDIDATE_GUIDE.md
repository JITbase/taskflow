# Guide du candidat — TaskFlow

Application volontairement imparfaite de gestion de tâches. Le dépôt est destiné à un exercice d'investigation technique en environnement local.

- Backend : NestJS + Mongoose + MongoDB
- Frontend : React + Vite
- Bonus : microservice Go
- Les données et secrets sont fictifs. Ne jamais déployer ce projet sur Internet ni y mettre de vrais identifiants.

## Contexte

Vous reprenez une petite application de gestion de tâches développée par notre précédent stagiaire. L'équipe souhaite une revue technique avant de poursuivre son développement.

L'application comprend :
- des utilisateurs et une authentification ;
- des projets et des tâches ;
- des commentaires ;
- une interface React ;
- un stockage MongoDB.

## Votre mission

En temps limité, explorez le dépôt et identifiez les problèmes qui vous semblent importants. Vous n'avez pas à tout corriger.

Le bonus Go est facultatif.

## Règles

- Vous pouvez utiliser la documentation, les moteurs de recherche et les assistants IA, dont ChatGPT.
- Vous pouvez exécuter les commandes, lire les logs et modifier le code.
