# Guide du candidat — TaskFlow

## Contexte

Vous reprenez une petite application de gestion de tâches développée par une autre équipe. L'équipe souhaite une revue technique avant de poursuivre son développement.

L'application comprend :
- des utilisateurs et une authentification ;
- des projets et des tâches ;
- des commentaires ;
- une interface React ;
- un stockage MongoDB.

## Votre mission

En temps limité, explorez le dépôt et identifiez les problèmes qui vous semblent importants. Vous n'avez pas à tout corriger.

Pour chaque problème signalé, fournissez :
1. le fichier et l'endroit concernés ;
2. une explication du problème ;
3. un scénario concret permettant de le constater ;
4. l'impact (sécurité, fiabilité, maintenabilité, performance ou expérience utilisateur) ;
5. une correction proposée.

Choisissez ensuite un problème important et corrigez-le. Ajoutez un test qui démontre le comportement attendu.

## Règles

- Vous pouvez utiliser la documentation, les moteurs de recherche et les assistants IA, dont ChatGPT.
- Vous pouvez exécuter les commandes, lire les logs et modifier le code.
- Ne connectez pas ce projet à un service ou une base de données contenant de vraies données.
- N'essayez pas de déployer l'application publiquement.
- Signalez les hypothèses et les points que vous n'avez pas pu vérifier.
- Un rapport court et précis vaut mieux qu'une longue liste de suppositions.

## Livrables

À la fin de l'exercice, remettez :
- une liste priorisée de vos constats ;
- les étapes de reproduction ;
- le correctif choisi ;
- les tests ajoutés ou exécutés ;
- les questions que vous poseriez à l'équipe avant une mise en production.

## Temps suggéré

- 15 min : prise en main et démarrage ;
- 45 min : backend et MongoDB ;
- 25 min : sécurité ;
- 20 min : frontend ;
- 20 min : correction et test ;
- 15 min : restitution.

Le bonus Go est facultatif.
